# نظام إدارة الجلسات المتعددة والأمان المتقدم

## نظرة عامة

تم تنفيذ نظام شامل لإدارة الجلسات المتعددة مع ميزات أمان متقدمة وواجهة قابلة للتخصيص.

## الميزات المنفذة

### 1. نظام إدارة الجلسات المتعددة

#### قاعدة البيانات
- **جدول `sessions`**: تخزين معلومات الجلسات
  - معلومات الجهاز (Device Name, IP, User Agent)
  - تواريخ الإنشاء والنشاط الأخير
  - حالة الجلسة (نشطة/ملغية)
  
- **جدول `user_security_settings`**: إعدادات الأمان لكل مستخدم
  - خيار السماح بجلسات متعددة
  - إعدادات المصادقة الثنائية (2FA) - جاهز للتفعيل

- **جدول `security_audit_logs`**: سجلات التدقيق الأمني
  - تسجيل كل نشاط أمني
  - معلومات IP و User Agent
  - بيانات إضافية (Metadata)

#### الوظائف الأساسية

**تسجيل الجلسات:**
- يتم إنشاء سجل جلسة تلقائياً عند تسجيل الدخول
- حفظ معلومات الجهاز والموقع
- مدة الجلسة الافتراضية: 7 أيام

**إدارة الجلسات:**
- عرض جميع الجلسات النشطة
- إنهاء جلسة محددة
- إنهاء جميع الجلسات (تسجيل خروج شامل)
- تحديث آخر نشاط تلقائياً

**السياسات الأمنية:**
- خيار السماح/منع الجلسات المتعددة
- عند تعطيل الجلسات المتعددة، يتم إلغاء الجلسات القديمة تلقائياً
- حماية RLS على جميع الجداول

### 2. صفحة الأمان (`/security`)

#### المكونات
- **نظرة عامة على الجلسات النشطة**
  - عرض معلومات كل جلسة
  - أيقونات تمييز نوع الجهاز
  - معلومات IP وآخر نشاط
  
- **إعدادات الأمان**
  - تبديل السماح بجلسات متعددة
  - إعدادات 2FA (قريباً)

- **إجراءات الأمان**
  - زر إنهاء جلسة محددة
  - زر إنهاء جميع الجلسات
  - تأكيد قبل الإجراءات الحرجة

### 3. Edge Function: `manage-sessions`

#### الأفعال المدعومة

```typescript
// إنشاء جلسة جديدة
{
  action: 'create',
  sessionToken: string,
  deviceName: string,
  userAgent: string,
  expiresAt: string
}

// إلغاء جلسة محددة
{
  action: 'revoke',
  sessionId: string
}

// إلغاء جميع الجلسات
{
  action: 'revoke_all'
}
```

#### الميزات الأمنية
- التحقق من هوية المستخدم
- احترام إعدادات الجلسات المتعددة
- تسجيل كل إجراء في audit logs
- استخدام Service Role للعمليات الحساسة

### 4. واجهة المحاسب القابلة للتخصيص

#### ميزة السحب والإفلات (Drag & Drop)

**المكونات:**
- `DraggableIconGrid`: شبكة الأيقونات القابلة للترتيب
- `SortableIconItem`: عنصر قابل للسحب
- `useDashboardLayout`: Hook لإدارة الترتيب

**الوظائف:**
- إعادة ترتيب الأيقونات بالسحب والإفلات
- حفظ الترتيب في قاعدة البيانات
- التبديل بين عرض الشبكة والقائمة
- استعادة الترتيب المحفوظ تلقائياً

**الجدول:**
- `user_dashboard_layout`: حفظ تخصيصات المستخدم
  - ترتيب الأيقونات
  - وضع العرض (grid/list)
  - تخصيصات إضافية

### 5. التحديثات على AuthContext

#### تسجيل الدخول
```typescript
// تسجيل جلسة جديدة عند Login
await supabase.functions.invoke('manage-sessions', {
  body: { action: 'create', ... }
});
```

#### تسجيل الخروج
```typescript
// إلغاء الجلسة الحالية عند Logout
await supabase.functions.invoke('manage-sessions', {
  body: { action: 'revoke', sessionId }
});
```

## الأمان والخصوصية

### Row Level Security (RLS)
- ✅ جميع الجداول محمية بـ RLS
- ✅ المستخدمون يرون جلساتهم فقط
- ✅ المسؤولون يمكنهم رؤية كل شيء
- ✅ سجلات التدقيق للقراءة فقط

### تسجيل النشاط
كل إجراء أمني يُسجل مع:
- معرف المستخدم
- نوع الإجراء
- IP Address
- User Agent
- معلومات إضافية

### حماية البيانات
- تشفير Tokens في قاعدة البيانات
- HTTP-only cookies (جاهز للتفعيل)
- تنظيف الجلسات المنتهية تلقائياً
